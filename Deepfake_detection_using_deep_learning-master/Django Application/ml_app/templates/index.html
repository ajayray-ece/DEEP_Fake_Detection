About the Project

This project employs advanced deep learning techniques, including Convolutional Neural Networks (CNNs) and pre-trained models like XceptionNet, EfficientNet, and Vision Transformers (ViT), to classify real and fake media.

The model is trained on publicly available datasets such as FaceForensics++, Celeb-DF, and DeepfakeTIMIT, and deployed as a web-based application to assist cybersecurity professionals in combating misinformation.
